Products and Solutions

A static site foundation with shared layout, token-based theming, and room to grow into fuller UI kits.

Starter Kit

A ready-made layout, theme tokens, and navigation pattern for marketing, docs, or lab sites.

  • Responsive header and mobile menu
  • Light / inverse theme toggle
  • Shared content width controls
  • Paper, ink, and accent tokens out of the box

Team Site

Extend the shell with extra pages, tables, and resource lists for internal or public use.

  • Reusable section and card styles
  • Simple static hosting friendly
  • Easy branding and copy swaps
  • Status labels and reference tables

Theme Core

Role-based color system that stays readable in light and inverse without rewriting components.

  • Surfaces on paper tokens
  • Type on ink tokens
  • Signal / confirm / alert accents
  • Hover, border, and background helpers

Future UI Kit

Planned patterns that build on the same tokens so new components inherit light and inverse automatically.

  • Forms, inputs, and validation states
  • Buttons and grouped controls
  • Alerts, toasts, and modals
  • Pagination and breadcrumbs

Use cases

Practical places this template—and a future expanded theme—fit well.

Product and marketing sites

Launch pages, feature grids, and pricing-style sections that share one header, footer, and accent language across every route.

  • Consistent CTA and link colors
  • Card-based feature blocks
  • Inverse mode for evening reading or demos

Docs and knowledge bases

Multi-page documentation with stable typography, width control, and tables for commands, options, and release notes.

  • Readable long-form content width
  • Resource tables for API or CLI notes
  • Theme tokens for tips, warnings, and success

Open-source project hubs

Repository companions that list downloads, licenses, status, and research notes without standing up a CMS.

  • License and stack reference tables
  • Component status lists
  • Links out to GitHub, docs, and contact

Research and lab notebooks

Lightweight public notes for design systems, performance defaults, and accessibility experiments tied to the same visual language.

  • Topic cards and sample snippets
  • Clear hierarchy with ink and accent roles
  • Fast static publish cycle

Internal team portals

Simple handbooks, onboarding checklists, and service catalogs that stay on brand in both light and inverse.

  • Shared shell for many short pages
  • Status chips for ownership and progress
  • Low maintenance on static hosts

Brandable theme starter

A base for future branded themes: swap token values once, keep component classes, and grow forms or overlays later without a redesign.

  • Role tokens instead of one-off hex values
  • Lum / base / dark steps for hierarchy
  • Path to a fuller component theme

Future theme directions

  • Form theme — inputs, labels, errors, and disabled states mapped to ink, neutral, and alert tokens
  • Feedback theme — inline alerts, toast stacks, and empty states using confirm, signal, and alert
  • Navigation theme — breadcrumbs, tabs, and side nav built on hover-accent and card surfaces
  • Data theme — denser tables, filter chips, and pagination for resource-heavy pages
  • Campaign variants — alternate accent presets (for example, stronger signal or softer neutral) without changing markup
